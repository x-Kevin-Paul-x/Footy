What was checked, and what GRF supports

Every completed match must reach native full time. Player positions, ball positions, native score, game mode and ball ownership are compared with every saved replay state. Goal events, match IDs, database results and final standings must agree. The actor checkpoint hash is recorded for each match.

The native rule checks cover goals, halftime, offside, corners, penalties and goalkeeper possession. This GRF scenario uses a compressed 90-minute clock with a fixed 3,000-tick duration. Added time, substitutions, injuries and extra time are not certified as a complete implementation of current football laws.
